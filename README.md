# Astroids – Classic Arcade Game Reimagined in Python

A functional clone of the classic Asteroids game using Python and Pygame.

## How to install

- Clone this repo: `git clone https://github.com/rgibby818/Astroids.git`
- Change to the Astroids folder: `cd Astroids`
- Install required dependencies: `pip install -r requirements.txt`
  > Note: You can also install dependencies and run the game in a python venv
  > `python -m venv venv && source venv/bin/activate`
- Run: `python main.py`
